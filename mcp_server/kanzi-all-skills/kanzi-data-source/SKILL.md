# 数据源预处理（data-source-process）

> 你是数据源预处理子会话。**只读数据源、提取字段、落盘中间文件、回报路径；不执行任何 Kanzi 操作**（kz_* 一律不调）。
> 中间文件供后续 Kanzi 子会话当 data_source 读取。

## 执行流程

1. **读任务描述单**：objective（提取目标）、constraints（字段/列名清单 + 中间文件路径约定）、data_source（原始大文件完整路径）。
2. **确认文件存在**：先确认原始文件存在、可读；不存在/打不开 → 直接回报失败（不猜、不脑补）。
3. **识别格式**：
   - `.xlsx/.xls` → openpyxl / pandas 读取
   - `.csv/.tsv` → csv 模块 / pandas 读取（注意编码：utf-8-sig / gbk 兜底）
   - `.json` → json.load（大文件用分块或直接读，控制内存）
   - `.txt/.md` → 按行读取
4. **分块/流式读取（禁止整读进上下文）**：
   - 大文件用脚本按需提取字段，**不把原始内容整段读进会话**；
   - 只输出提取后的结构化结果（小 JSON），原始大文件内容不进回报。
5. **提取字段**：按 constraints 指定的字段/列名提取，缺失字段报出来（不脑补默认值）。
6. **落盘中间文件**：
   - 路径：`workfile/parsed/<数据源名>.json`（相对 working_directory；constraints 指定了别的路径就用指定的）；
   - 结构：`{"source": "<原始路径>", "count": <条目数>, "items": [ {...}, ... ]}`；
   - 用脚本写文件（json.dump ensure_ascii=False, indent=2），**内容不进会话上下文**。
7. **验证**：读回中间文件，确认条目数 = 预期（constraints 有数量要求时核对）、字段齐全。
8. **回报**：
   - ✅ 成功：`✅ 数据源预处理完成：中间文件 <路径>，条目数 N，字段 [a, b, c]`
   - ❌ 失败：`❌ 数据源预处理失败：<第几步、哪个文件、什么错误>`

## 执行总则

1. **不执行 Kanzi 操作**：本类型只处理数据文件，不调 kz_*、不连 Kanzi Studio。
2. **大文件禁止整读**：原始文件内容不进会话上下文，只用脚本提取必要字段。
3. **编码兜底**：csv/文本先试 utf-8(-sig)，失败试 gbk（Windows 导出文件常见）。
4. **不脑补**：字段缺失/格式不符 → 回报失败并说明，不自行造默认值。
5. **中间文件结构固定**：`source` / `count` / `items` 三字段，供后续子会话统一读取。
6. **回报只给路径+数量+字段名**：不回原始内容、不逐条复述。
7. **特殊字符清洗/转义（2026-11-09 加，防下游 JSON 解析炸）**：文本字段常含换行/引号/反斜杠，**提取时就在源头处理**：
   - **换行**：多行文本（如 `动力电池状态无法监控\n请联系经销商`）在中间文件里存**转义序列 `\n`**（JSON 里显示为 `\n`，即反斜杠+n 转义；读回 `json.loads` 还原为真换行符），**不要存真换行符**（真换行符会破坏 JSON 字符串）—— 写入前统一 `text.replace("\n", "\\n").replace("\r", "")`（把真换行替换成反斜杠+n 两个字符，与 JSON 转义一致，不是存两个反斜杠）。
   - **引号/反斜杠**：数据含双引号/反斜杠时不手拼 JSON —— 落盘用 `json.dumps(items, ensure_ascii=False, indent=2)` 自动转义；
   - **验证**：落盘后读回 `json.loads` 一次确认合法（`Unterminated string` 说明源头还有未清洗的换行/引号，回头处理）。
   - 下游 Kanzi 子会话读取时用 `json.loads` 得到原样字符串，再按需处理（含真换行的文本设给 TextConcept.Text 用 `@string:` 传，见执行协议 JSON 转义规范）。

## 常见坑

- **xlsx 读取**：本机无 openpyxl 时用 pandas（`pd.read_excel`）；都没有 → 回报「缺库」，不硬编。
- **列名含特殊字符**：提取时按 constraints 给的列名精确匹配；列名带空格/括号用 `df.columns` 核对后引用。
- **空值处理**：空单元格 → null/空串，标注「该字段有空值」。
- **超大文件**（几百 MB+）：用 pandas `chunksize` 或按行流式处理，避免内存爆。
